## 📖 项目简介

### v0.30.2：章节间贴与作者作品集

- 阅读器长按正文可选择「本章间贴」，展示官方公开接口中的真实读者昵称、角色称号、正文、时间、点赞和回复数，并支持最热与最新切换。
- 间贴按章节读取，引用框只标记用户当前长按的阅读位置；官方返回的 `row` 与本地分页不存在可验证的一一映射，因此界面不声称交互精确到该句。
- 书籍详情的作者入口改为读取官方移动网页中的“作者作品集”，从真实书号逐本补齐现有 App 详情数据；接口格式变化和空作品集分别提示，不伪造作者作品。
- 吐槽真实字段、作者作品集解析、容器变化与畸形响应均补充单测；匿名实测读取两位作者的 7 部和 10 部作品，以及同书前三章 5、5、4 条间贴。

### v0.30.1：漫画连续阅读与界面整理

- 漫画目录读取站点真实总页数，滚动到底自动追加下一页，修复“全部”分类只显示少量作品的问题。
- 漫画阅读页只保留底部固定章节导航；章末不再重复显示一组按钮，继续下滑会加载下一话。
- 切换章节后自动回到新话首张图片；搜索框与按钮统一高度、圆角和对齐方式。

### v0.30.0：漫画入口与原生阅读

- 菠萝包首页原「分类找书」大按钮改为「漫画」，页头恢复「搜索和分类找小说」入口，保留新书推荐和全部小说功能。
- 接入 SF 漫画网站的分类目录、关键词搜索、作品目录、章节图片列表与原生图片阅读，读取范围仅为当前公开可访问章节。
- 漫画站点使用独立的公开 Web API，与小说 App 接口分开；请求限制在已确认的漫画域名，不读取或复用小说账号会话。
- 漫画目录接口只提供当前页作品，分页极限由网站返回决定；图片列表异常、限流和空章节均显示明确状态。

### v0.29.0：阅读与组合筛选修复，新书推荐和相关书单

- 免费章节、目录和搜索等匿名只读请求遇到 417 时，最多尝试三次，每次重新签名，重试前分别等待 1 秒、2 秒；不携带账号 Cookie，也不将签名错误记为账号风控。
- 登录、账号请求和付费章节不自动重试；遇到安全验证、限流或客户端标识拒绝立即结束本次操作。
- 阅读器只在确实需要登录时显示登录引导；签名失败显示对应说明，保留手动重新加载。
- 分类和作品标签改用真实筛选接口，支持分类与多个标签同时生效；选择、移除标签、刷新和翻页均保留其余条件，不再将标签拼成搜索词。分类列表从平台元数据加载。
- 修复筛选选项加载与首屏请求相互取消、切换条件后旧分页结果混入、分页失败反复自动请求的问题；筛选状态由 ViewModel 统一保存。
- 新增匿名可用的新书推荐页和作品详情「相关书单」入口，支持刷新、分页及点开作品；相关书单区分平台标注的总书数与接口实际附带的预览作品数，明确提示非完整书单。
- Release APK 已构建并在 Android 9 模拟器验收组合筛选、翻页、新书推荐与相关书单；签名与 v0.28.0 一致。详见 [验证记录](docs/v0.29.0-verification.md)。

### v0.28.0：精彩书评读者讨论区与云端书架端点彻底修复

- **菠萝包云端书架真实端点修复**：彻底修复加入云端书架提示“未返回可识别数据”的 Bug，对齐官方真实写入路由 `POST /pockets/{pocketId}/novels`，云端同步收藏 100% 成功。
- **精彩书评与读者讨论模块**：全屏书籍详情页新增「读者书评」区域，对接官方 `novels/{id}/Cmts` 接口，展示读者头像、昵称、VIP 等级、评论正文与点赞数，与广大书友同频共振。

### v0.27.0：同步加入菠萝包云端书架与多标签精准检索

- **同步加入菠萝包云端书架**：在书籍详情页新增「加入菠萝包云端书架（CloudUpload）」功能，一键将作品同步收藏至用户的菠萝包官方账号书架（默认书夹 `-1`），并提供即时反馈。
- **多标签筛选精准生效**：彻底修复标签筛选失效的问题，将「想看的作品标签」多选结果（如「异世界 + 变身」）与官方检索接口深度对接，支持多选标签即时交集过滤、胶囊条单个移除与一键重置，找书直达目标。

### v0.26.0：悬浮窗同书自动隐匿、温和流控自锁移除与书架秒开

- **朗读悬浮窗精准显隐**：修复正在朗读的小说本体在阅读器中显示悬浮窗的 Bug，只有退出该小说或在读其他小说时才浮现悬浮胶囊，阅读本体纯净沉浸。
- **温和队列流控（彻底根治点进书架误触发熔断）**：移除本地自残式的 30 分钟自锁死与 50 章自设配额，改为平滑无感的协程微排队流控；仅当官方明确返回 1148 安全验证时才温和提示，书籍加入书架后点击秒开，不再弹出熔断警告。

### v0.25.0：AI助手中转站兼容性修复、400报错透传与跨书听书音画解耦

- **AI 助手第三方中转站 HTTP 400 彻底根治**：针对第三方中转网关自动剥离易引起拒绝的 `stream_options` 字段，并全面透传服务端真实的 HTTP 400 详细错误信息（而不是盲目丢弃），中转站流式问答即刻畅通。
- **跨书朗读音画错乱彻底修复**：当后台正在朗读一本书而用户在阅读器进入另一本书时，严格禁止新书强占后台播放器上下文，新书段落绝不高亮、底栏隐藏朗读条，并在界面右上角无缝悬浮显示后台正播放书籍的控制胶囊。

### v0.24.0：去星级纯净看板、分类无限触底翻页与试读/加书架彻底解耦

- **去星级纯净核心看板**：依照阅读习惯移除不必要的评分星级（★），详情页与列表专注呈现官方真实点赞数、月票数、收藏量与人气指标。
- **分类找书支持触底无限翻页**：彻底解决此前只能浏览前 20 本的问题，接入动态分页引擎（Page 0, 1, 2, 3...），滑至列表底部自动静默追加加载下一页，找书顺畅无尽头。
- **在线试读与加入书架彻底解耦**：数据库引入 `inBookshelf` 标识（Room Migration 2 -> 3）；在线打开、试读、查看目录的书籍绝不自动污染本地书架，只有在详情页显式点击「加入书架」按钮才会入库，书架支持随时移除。
- **锁定菠萝包书籍官方封面**：书架端长按更多菜单对菠萝包书籍自动隐藏“更换封面”和“恢复默认封面”，杜绝误操作修改或抹除官方封面。

### v0.23.0：官方全量标签动态直采、多选标签筛选器与熔断强制解除

- **官方全量系统标签动态直采**：接入官方 `novels/0/sysTags` 接口，动态拉取菠萝包线上实时更新的全量 69 个官方系统标签，告别本地硬编码。
- **1:1 官方复刻「想看的作品标签」多选器**：在分类找书页右上角增加漏斗图标，呼出三列网格多选弹窗（对齐官方 App Image #11）；支持多标签任意组合勾选（如同时选「异世界 + 变身」）、重置与确定，直接对接官方多标签过滤接口 `novels/0/sysTags/novels?sysTagId=...` 精准筛选。
- **安全熔断无视风险继续使用**：在安全熔断告警卡片（`SfSafetyNotice`）中新增「无视风险继续」快捷操作，支持随时一键强行解除 30 分钟冷却限制，不再被动等待。

### v0.22.0：官方系统纯净标签、多级平铺分类库与详情页三大指标

- **书籍详情页三大核心指标卡片**：完全对齐官方详情页三大核心指标（【总字数 / 完结状态】·【月票数】·【点赞数（如 13.8万）】），并在标题卡片呈现收藏量与好评星级。

### v0.21.0：全屏分类找书库、书架网络封面持久化与全套风控安全加固

- **全新全屏分类找书库（SfBrowseScreen）**：独立全屏二级找书与榜单页面，彻底根除此前底部弹窗在急速滑动时的嵌套手势冲突与上下抽搐；支持畅销总榜、人气月榜、飙升周榜、最新更新即时切换与关键词深度搜索。

- **全套风控安全加固与熔断落地**：打通并完善 Codex 的安全防护套件，敏感会话采用 `SecretEnvelope` 与硬件级 Android Keystore 加密封存；全面接入 `SfRequestGuard` 单例限速、指数退避策略与 30 分钟风控熔断机制，严防被平台拉黑与封号。

### v0.15.0：菠萝包账号书架与在线阅读

- 在「发现 → 菠萝包 SF」使用账号/手机号和密码登录。App 会话通过 Android Keystore 加密保存；密码只用于本次登录，不落盘。原网页 Cookie 输入入口已移除。
- 登录后读取账号书架及分类；点选作品或输入官方书籍链接打开目录，进入原生阅读器按章加载。只读平台数据，阅读进度保存在本应用。
- 免费和账号已有购买权限的章节可在线阅读、听书、缓存及下载。遇到安全验证（1148），请先在官方菠萝包 App 完成，再回来重新登录。应用不会购买章节。
- 阅读器右上角「更多 → 下载与导出」支持本章、范围和全书下载，以及 TXT / Markdown / EPUB 导出。缺章时列出未购和失败章节，明确确认后才能导出不完整版本；文件附有缺章说明。
- 任务可暂停、继续或重试；成功正文持久化保存，重新打开应用可继续上次任务。任务属于应用进程，系统结束进程后需要手动继续。
- 自动缓存已读正文；发现页可查看及清理缓存，清理时保留主动下载。退出账号清除会话和远端书架信息，保留本地正文和进度；可在本地书架删除书籍。
- Room 1 → 2 使用非破坏性迁移，并清理旧版被误存为正文的抓取错误提示。AI 伴读检索只使用本地已有正文，不自动下载全书。

验证命令与协议来源见 [菠萝包接入说明](docs/sfacg-integration.md)。实际账号登录、私有书架与已购 VIP 验收需要由账号持有人在应用内完成；匿名公开接口验证不能替代这一验收。

**AI 智阅小说（NovelAI Assistant）** 是一款面向数字阅读爱好者的现代全格式电子书阅读器，深度融合了**上下文长文本 AI 伴读助手（RAG/Agent）**与**沉浸式 AI 连续续写及平行世界分支推演**能力。

应用坚持 **BYOK (Bring Your Own Key)** 原则，作为纯本地客户端运行，无需第三方中继服务器。用户自主填入大模型 API Key（兼容所有 OpenAI 规范接口），敏感数据使用 **Android Keystore 加密存储于本地**，杜绝数据外泄与账号跑路风险。

整体视觉遵循 **iOS Human Interface Guidelines (HIG)** 设计美学，融合 Squircle 大圆角矩形、实时高斯模糊毛玻璃（Frosted Glass）、弹性物理动效与深度护眼的全深色模式。

## ✨ 核心特性矩阵

### 1. 📚 沉浸式阅读引擎 (Reader Engine)
- **多格式导入支持**：无缝支持本地 `.txt`、`.epub`、`.md` 等电子书解析与阅读。
- **双阅读排版模式**：
  - **仿真左右翻页（Paged，默认）**：重写高精度换行与分页算法，杜绝多段落死锁排版故障；支持屏幕左右点击翻页、跨章平滑过渡与首末页手势阻尼。
  - **无缝上下滚动（Scroll）**：平滑垂直连续长卷阅览。
- **高自由度排版定制**：亮度、字号（A-/A+）、行距、边距、段距自由微调；内置衬线体（Serif）与无衬线体一键切换。
- **5 套经典阅读主题**：白天纯白、羊皮纸米黄、豆沙绿护眼、暗夜深蓝、OLED 极暗纯黑。
- **目录抽屉与长按章节管理**：
  - 智能正则提取目录与原生 EPUB 目录映射；
  - 支持 **[全部] / [仅原作] / [AI衍生] / [分支树]** 四维目录筛选；
  - 目录内**长按任意章节**呼出操作菜单，支持章节**重命名**与**安全永久删除**。

### 2. 🎧 智能语音听书与系统媒体控制 (TTS & Media Controls)
- **系统级媒体卡片组件 (System Media Controls)**：
  - 接入 Android 原生 **MediaSession** 与 **MediaStyle** 前台媒体服务（`foregroundServiceType="mediaPlayback"`）；
  - 系统下拉通知中心、锁屏大号胶囊及各类定制系统（MIUI/HyperOS、ColorOS、OriginOS、OneUI）原生展示精美媒体播放器卡片；
  - **后台与息屏保活**：切出应用、灭屏锁屏时像听音乐一样稳定持续播放，支持通知栏与蓝牙耳机直接进行**播放/暂停、上一章、下一章、停止**；
  - 点击通知栏卡片一键平滑跳转并恢复当前书籍阅读器。
- **听书定时停止 (Sleep Timer)**：
  - 支持 **15 / 20 / 30 / 45 / 60 / 90 分钟** 倒计时自动停止；
  - 支持睡前专属**「听完本章停止」**模式；
  - 支持**「不设置（听到全书完）」**，持续自动跨章连播直至全书终章。
- **智能选段与段落高亮跟随**：
  - 支持类似番茄小说的**从当前屏幕所在页首段直接起播**；
  - 正文长按任意文字片段呼出浮层，支持**「从此处朗读」**；
  - 听书朗读期间对应段落实时以**柔和紫色微光高亮**跟随，自动驱动仿真翻页连播。
- **听书控制胶囊**：底部常驻播放/暂停切换、停止按钮、**实时倒计时胶囊**与 **0.75x ~ 2.0x 无级语速调节**。

### 3. 🤖 AI 深度伴读与划线即问 (RAG & Chat)
- **划线即问浮动胶囊**：阅读过程中长按任意文字片段，即时呼出操作胶囊：
  - **「解析深意」**：剖析选段伏笔、行文手法与隐喻；
  - **「情绪总结」**：解析段落情感基调与人物内心；
  - **「AI 吐槽」**：以幽默辛辣口吻即兴吐槽。
- **独立 AI 伴读助手主页**：
  - 支持**情节回忆**（回忆前文线索）、**人物图谱分析**（人物关系与生平）与**剧情深读**；
  - **原生文本自由选择**：采用原生 `SelectionContainer`，长按自由框选与复制，杜绝粗暴自动复制整段；
  - **即时交互视觉反馈**：发送后展现思考动画气泡、输入框顶部线性进度条与流式输出动态光标；
  - 提供**清空聊天记录**功能（含二次确认对话框）。

### 4. ⚡ AI 连续续写与平行世界分支 (Continuation & Branching)
- **全书最新章追踪**：续写默认开启「⚡ 全书最新章」直接追踪模式，无需在长篇目录中反复寻找末尾章节；亦可自由切换指定章节。
- **连续续写模式**：新章生成后支持一键「保存并续写下一章」，自动将新章作为下一轮创作前驱，顶部配有创作链路进度条。
- **因果世界线追溯算法（`getChapterLineage`）**：分支推演严格向上溯源至该分支归属的历史世界线祖先节点，剔除无关主线噪音，保证设定连贯。
- **剧情分支树（Branch Tree）**：树状可视化展现主线与平行宇宙衍生分支，节点支持一键「续写此分支」或「创建新分支」。
- **章节身份标识**：`[原]` 原作章节、`[AI]` AI 续写章节、`[分]` 平行分支章节。

### 5. 🔑 BYOK 多模型中心与任务分流 (Model Routing)
- **九家厂商预设与平台选择**：DeepSeek、Anthropic、OpenAI、Google、智谱、阿里云百炼、Moonshot、xAI、腾讯混元；保留自定义入口，硅基流动、Ollama 及中转站可填写各自地址。
- **四种独立 API 协议**：Chat Completions、Responses、Anthropic Messages、Gemini，支持自定义 Base URL、Key、模型 ID 和请求头。
- **真实生效的多场景分流**：
  - 为**续写场景**指定长文本拟合能力强的高阶模型（如 Claude 3.5 Sonnet / DeepSeek-V2.5）；
  - 为**速览伴读场景**指定响应极速的轻量模型（如 GPT-4o-mini / DeepSeek-Lite）。
- **实用配置支持**：横向平滑滚动服务商卡片、一键设为默认、连通性 Ping 测试、自动获取模型列表、顶部常驻使用文档指南、清空用量统计防误触二次确认。

### 6. 🎨 深度全深色模式与主题适配 (Dark Mode)
- **完善的 Material 3 暗色色彩规范**：补全完整 `surfaceContainer*` 容器色系，消除弹出浅色底板的晃眼隐患。
- **双重深色模式感知**：无论是**系统开启深色模式**还是**阅读器选择暗夜/极暗背景**，弹出的阅读设置面板、长按章节菜单、重命名/删除弹窗、划线选段操作条均自动无缝适配为舒适暗黑质感。

## 🚀 快速上手与编译构建

### 环境要求
- **Android Studio**：Ladybug (2024.2.1) 或更高版本
- **JDK**：OpenJDK 17
- **Android SDK**：Compile SDK 34，Min SDK 26 (Android 8.0+)
- **Gradle**：8.7+

### 本地编译步骤
1. **克隆仓库**：
   ```bash
   git clone https://github.com/Zuo-yan/NovelAIAssistant.git
   cd NovelAIAssistant
   ```

2. **编译 Debug 版**：
   ```bash
   ./gradlew assembleDebug
   # 产物输出于：app/build/outputs/apk/debug/app-debug.apk
   ```

3. **编译 Release 版（安装包）**：
   ```bash
   ./gradlew assembleRelease
   # 产物输出于：app/build/outputs/apk/release/app-release.apk
   ```

4. **安装至连接的手机或安卓模拟器**：
   ```bash
   adb install -r app/build/outputs/apk/release/app-release.apk
   ```

## 📱 使用指南

1. **导入书籍**：
   - 首次进入主界面点击右上角「导入」按钮，选取本地 `.txt` 或 `.epub` 小说；
   - 系统将自动解析章节目录并加入书架。
2. **配置大模型 (BYOK)**：
   - 前往底部「设置」→「模型与 API」→ 点击「添加提供商」；
   - 填入您的 Base URL（如 `https://api.deepseek.com/v1`）与 API Key；
   - 点击右上角「📖 使用文档」可随时查阅各参数详细说明；
   - 在「任务分流」中为续写与伴读分别指定合适的模型。
3. **沉浸式阅读与听书**：
   - 点击书架书籍进入阅读器，点击屏幕左/右侧翻页，点击中间呼出菜单栏；
   - 点击底部「听书」即可从当前页首段自动语音朗读；
   - 长按任意文字片段呼出快捷浮层，一键「从此处朗读」或「解析深意」。
4. **AI 连续续写与平行分支**：
   - 点击底栏「AI 续写」自动定位最新章节，输入导向设定即可生成后续章节；
   - 生成后点击「保存并续写下一章」可无缝连续推演；
   - 点击顶部「分支树」可查看剧情分叉节点，随时推演全新世界线。
