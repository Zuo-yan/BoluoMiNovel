# 菠萝包接口盘点（2026-10-22）

这些是社区客户端使用的 App 接口，不是菠萝包提供的公开开发者服务。下表的“已实测”仅表示本日在无账号 Cookie 的情况下取得相应响应，不保证以后持续可用。

## 本轮已实现

| 功能 | GET 路径与关键参数 | 实测结果 |
| --- | --- | --- |
| 新书推荐 | `/novels/specialpushs?pushNames=newpush&page=0&size=3` | `data.newPush` 返回 3 条推荐，每条的 `novel` 包含作品信息；已接入独立页面 |
| 相关书单 | `/novel/540307/bookList?page=0&size=3` | `data.items` 返回相关读者书单；示例书单标注共 30 本，实际附带 3 本预览；已接入详情页入口和预览页 |
| 动态分类 | `/noveltypes` | 8 个分类，魔幻 21、玄幻 22、古风 23、科幻 24、校园 25、都市 26、游戏 27、悬疑 29 |
| 全部作品标签 | `/novels/0/sysTags` | 返回 69 个标签；与分类 ID 是两个独立维度 |
| 分类与多标签组合 | `/novels/{分类ID}/sysTags/novels?systagids=22,58` | 魔幻与科幻分别返回符合“异世界＋恋爱”的作品；所有抽样作品的分类、标签均与请求相符 |

相关书单首版提供接口返回的预览作品，不承诺完整书单。界面同时展示总书数和实际预览数；作品可以进入现有详情页与阅读器。空结果、加载失败分别显示，支持手动刷新、重试和分页。没有新增自动后台请求或账号写入。

## 筛选故障原因

- 原 ViewModel 将选中的多个标签名称拼成关键词搜索，无法表示标签交集。
- 原接口适配传 `sysTagId=22,58`；对照实测，该参数未过滤结果，而 `systagids=22,58` 返回的作品均包含两个标签。
- 原大类按钮同样调用关键词搜索，覆盖标签筛选模式；现改为统一的 `SfBrowseFilter`，分类放入路径、标签放入查询参数。
- 清除分类保留标签；清除标签保留分类；刷新、排序与分页复用同一组条件。筛选时提供已核验的“人气最高”和“最新更新”排序。
