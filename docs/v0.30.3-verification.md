# v0.30.3 验证记录

日期：2026-10-22（香港时间）。版本字段为 versionCode 33、versionName 0.30.3。

## 已实现

- 菠萝包章节正文与评论摘要改为一次只读加载。章节接口的 `expand.tsukkomi` 明确提供 `row` 和 `count`，界面仅对 `count > 0` 的段落显示右侧间贴气泡与数字。
- 正文保留服务器段落行（包括空行），不再把相邻行合并为双换行，避免 `row` 下标整体偏移；本地书及 AI 章节不显示间贴入口。
- 间贴支持段落定位、最热／最新、继续分页和错误重试；普通纯文本章节的长按菜单中不出现“本章间贴”。
- 间贴的楼中楼回复可按需展开，显示真实昵称、头像、角色、正文与时间，并按回复编号去重。
- 书籍详情的读者书评取消前 10 条截断与单页限制，提供继续加载、错误重试、正在加载和全部到底状态；重复跨页条目按 `commentId` 去重。

## 真机接口实测

以下均为匿名只读 GET，不携带账号 Cookie，不执行点赞、回复、发表、关注、购买或书架写入。

- `GET /Chaps/6367390?expand=content,expand.content,tsukkomi,chatlines`
  - 返回完整公开正文；
  - `expand.tsukkomi` 返回 66 个段落计数，含第 0 段 46 条、第 8 段 165 条、第 20 段 1 条等；
  - 证明段落级徽标有服务器权威的 `row/count` 来源。
- `GET /novels/540307/Cmts?page=0&size=20&type=clear&sort=smart&replyUserId=0`
  - 返回 20 条书评，第一条与最后一条编号分别为 17919000、17904714。
- `GET /novels/540307/Cmts?page=1&size=20&type=clear&sort=smart&replyUserId=0`
  - 返回 3 条更早书评，第一页和第二页评论编号交集为 0，说明历史分页有效。
- `GET /chaps/0/6367390/tsukkomis?page=0&size=20&sort=hot&row=0&expand=vipLevel,avatar,roleName,widgets,growup,replys`
  - 样本吐槽 `35702792` 的 `expand.replys` 返回 3 条真实回复，而 `replyNum` 为 10；
  - 回复条目含 `replyId`、正文、回复时间、`replyUser.nickName`、头像与角色名；
  - 界面在按需展开时如实注明首屏仅返回最近若干条，不将部分回复误报为全部。
- 公开工具 `tools/Test-SfPublic.ps1` 已更新为兼容当前 Windows PowerShell 的网络请求与 MD5 实现，并继续限制为只读路由。

## 边界

段落评论接口仍按章节 ID 和 `row` 查询；如果平台未来删除摘要或修改行号语义，客户端会隐藏徽标而保留正文阅读。回复展开字段在样本中最多返回 3 条而总数可能更多，界面明确提示仅为已返回的最近几条。当前验证使用公开章节和匿名间贴，登录态、已购章节、极端大字号以及本地书视觉路径仍需单独确认。
