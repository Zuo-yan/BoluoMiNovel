# v0.16.0 实现与验证

日期：2026-10-16。版本号 0.16.0 / versionCode 16。项目使用原生 Kotlin + Compose，没有引入 TypeScript AI SDK。

## 界面调整

| Before | After | Why |
| --- | --- | --- |
| 发现页混合多个书源与管理操作 | 底栏与页头为「菠萝包」，番茄通过右上角更多进入独立页面 | 高频操作围绕菠萝包选书，其他书源仍易于找到 |
| 登录、书号、缓存与下载操作占据首屏 | 紧凑账号入口、继续阅读卡、带封面的舒适列表；管理功能放入加号／更多 | 先看到书名、作者和本机进度，减少操作竞争 |
| 选择书籍后先进入目录 | 点击直接继续阅读；书籍更多中进入独立目录或下载导出 | 常用路径更短，首次仍从第一章开始 |
| 顶级导航也使用较长位移动效 | 顶级页面短淡入，子页保留短过渡，原生点击反馈 | 缩短反复切页的等待感 |

保留原有配色、圆角与玻璃底栏。登录后的远端书架和未登录时的本机菠萝包书籍共用封面列表；退出仍能阅读本地内容。

## 模型协议与迁移

| 协议 | 生成路径 | 鉴权 | 输出参数 |
| --- | --- | --- | --- |
| OpenAI Chat Completions | `/chat/completions` | Bearer | `max_tokens` 或 `max_completion_tokens` |
| OpenAI Responses | `/responses` | Bearer | `max_output_tokens` |
| Anthropic Messages | `/messages`（基础地址含 `/v1`） | `x-api-key`、`anthropic-version` | `max_tokens` |
| Google Gemini | `/models/{model}:streamGenerateContent?alt=sse` | `x-goog-api-key` | `generationConfig.maxOutputTokens` |

- 接收完整 SSE 帧及多行 data，区分正文与思考事件；用量按每次请求累计值处理，不重复相加。错误及提前断流保留已收到文字并提示；取消向下传播至请求。
- Responses 设置 `store=false`。不把 Key 放进 Gemini URL；禁用自动重定向，避免把鉴权转发给其他站点。模型接口连接成功只表示模型接口可达，不宣称实际生成成功。
- v0.15 的客户端实际统一使用 Chat，即使旧配置 kind 标成 ANTHROPIC。因此旧版配置升级时保留 Chat 与原来的 `max_tokens`，新建配置才使用明确选择的协议。
- 不更改书籍数据库版本，不清空书籍、正文、进度、账号会话和已有 API 配置。仍保留此前 Room 1 → 2 的迁移。

## 平台与上限识别

九家厂商加自定义入口。每次选择厂商后都需要明确选平台／地域，包括只有一个入口的厂商；百炼 Workspace 入口额外填写 Workspace ID。更换厂商／平台会清空旧 Key、模型和请求头，防止把其他平台的凭据带过去。

自动上限：先读取选定地址的模型元数据；Google 的 `outputTokenLimit`、Anthropic 的 `max_tokens` 以及兼容接口明确提供的输出上限可直接使用。`0`、null、负值不作为有效上限。模型列表支持分页，Gemini 过滤不支持文本生成的模型。

内置回退仅用于已核验的精确官方域名、协议和模型 ID：OpenAI 的 GPT-4o mini、GPT-4.1（含列明的日期版本）、GPT-6 Sol、GPT-6.1 Sol，以及 DeepSeek 的 deepseek-flash、deepseek-v4-pro。DeepSeek 文档仅将上下文写作 1M，此处不猜测精确整数，上下文仍显示未知。未列出的模型依赖接口元数据，无法识别就保留当前数值并明确提示；不会按模型名字猜中转站上限。

基础地址、模型、协议、Key 或请求头改变会取消旧检测并重新识别。检测响应仅作用于仍匹配的配置；切换为手动后，迟到的结果只更新能力说明，不覆盖输出数值。自动模式的输出上限可能包含模型思考预算，不保证正文长度。
