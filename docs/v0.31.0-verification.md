# v0.31.0 验证记录

日期：2026-10-22（香港时间）。版本字段为 versionCode 35、versionName 0.31.0。

## 已实现

- **完整楼中楼回复**：新增只读接口 `tsukkomis/{吐槽编号}/replys`，点击“查看回复”后独立加载，不再只依赖首屏附带的 3 条；加载中显示进度，失败可单独重试，末尾如实标注“已显示 N 条可见回复”。
- **章节插图**：正文中 `[img]…[/img]` 与 HTML `<img src>` 两种形态都保留并识别为插图；翻页模式独占一页，可点击放大、双指缩放、还原和重新加载；听书遇到插图行朗读为“插图”，不会念出链接。
- **精确阅读进度**：按章节、段落与段内偏移保存阅读位置，翻页与滚动两种模式都支持；重新进入书籍回到原处，段落空白或分页变化时会回退到最近可见页。
- **书架追更**：手动“检查书架更新”读取最新章节、更新时间与未读章数，结果保存在本机；只对新增章节提供下载入口，不做后台轮询。
- **间贴面板排版**：引文与“最热／最新”并排，取消排序独占整行；有讨论的段落引文用左侧色条标出，面板头部与列表间距收紧。
- **长按浮动菜单**：由横向滚动改为按行换行的 FlowRow。原实现在大字号或窄屏下会把菜单整体撑出屏幕，末尾的“本章间贴”落到不可点区域；现在最多每行 3 个，全部入口可见可点。
- **目录页接入追更**：在章节目录也可直接看到该书更新信息与新增章节下载入口。

## 匿名真实接口

均为匿名只读 GET，不携带账号 Cookie，不执行点赞、回复、发表、购买或书架写入。

- `GET tsukkomis/35702792/replys?expand=avatar%2CroleName`：返回 6 条回复，字段为 `replyId`、`content`、`replyDate`、`replyUser.nickName`、`replyUser.expand.avatar`、`roleName`。
- 回复接口忽略 `page` / `size` 参数：追加 `page=0&size=50`、`page=1&size=50` 均仍返回同样 6 条，因此界面按“可见回复”如实标注，不伪造分页。
- `GET novels/540307?expand=…`：`latestChapTitle` 为空，但 `lastUpdateTime` 有效；最新章标题改由刷新后的目录补齐。
- `GET Chaps/6367390?expand=content%2Cexpand.content`：本章样本无 `<img>` 标签，插图解析以单元测试与已有模拟器样本验证。

`tools/Test-SfPublic.ps1` 的只读探针白名单已加入 `tsukkomis/{id}/replys`。

## 边界

- 回复接口在样本中最多返回 6 条而 `replyNum` 可能更大，客户端不承诺看到全部回复。
- 追更为手动触发，不提供推送提醒；章节标题依赖目录刷新，作品详情缺失该字段时以目录最后一章替代。
- 插图行在翻页模式独占整页；极端小屏或超大字号下仍按整页宽度缩放。
