# v0.29.0 开发验证记录

日期：2026-10-22（香港时间）。版本字段为 versionCode 29、versionName 0.29.0；按用户要求暂不打包 APK。

## 修复与实现

1. 匿名只读请求遇到 417 时，最多发送三次，每次重新生成签名；第二、三次请求前分别等待 1 秒和 2 秒，并继续经过共享队列。登录、携带账号会话的请求、付费章不自动重试。1148、安全验证、429、507 及其他错误终止当前操作。
2. 阅读器根据实际异常类型显示说明，不再固定引导登录。签名失败不写入账号风控状态；取消阅读会取消待执行的签名重试。
3. 分类与多标签通过同一个筛选状态保存，使用分类路径和 `systagids` 参数，不再借助关键词搜索。刷新、分页、移除单个标签、清空标签或分类均保留其他条件；旧分页不能混入新结果。
4. 分类和标签元数据独立加载，避免首屏请求互相取消；旧操作结束不能覆盖新操作的加载状态。分页失败后提供手动重试，不反复自动请求。
5. 菠萝包首页增加新书推荐入口；菠萝包作品详情增加相关书单入口。推荐、书单为独立原生页面，支持加载、空、错误、刷新、分页状态和作品详情跳转，不会自动添加到本地书架。
6. 相关书单保留总书数与实际预览数的区别；示例书单总计 30 本，仅附带 3 本预览，界面明确标注并允许点开这些预览作品。
