# v0.32.0 验证记录

日期：2026-10-23（香港时间）。版本字段为 versionCode 36、versionName 0.32.0。

## 已实现

- **液态玻璃渲染核心（`ui/components/Glass.kt`）**：
  - 新增 `Modifier.liquidGlass` 与 `Modifier.staticLiquidGlass`，向后兼容 `Modifier.glassEffect` 与 `Modifier.staticGlass`。
  - **AGSL 原生物理透镜折射与色散（Android 13+ / API 33+）**：编写 `RuntimeShader`，利用圆角超椭圆 SDF 计算法线向量，对底层做 UV 弯曲折射，并分别分离 R、G、B 通道模拟三棱镜色散。
  - **多重光谱色散环与凸透镜焦散（全版本兼顾）**：Compose Canvas 绘制层叠加青-紫-琥珀色散高光轮廓、凸透镜内凹倒角与全反射折射暗线，底色透光度提至 38%，彻底告别乳白塑料感。
  - **环境光晕（`AmbientBackdrop`）**：在全屏底层注入主题色微光晕，为玻璃提供持续透射折射光源。
  - 支持可选平滑液态流动光带（`Liquid Sheen Sweep`），在控件底层流转，不遮挡文字与图标对比度。
- **底部浮动导航栏液态玻璃升级（`GlassBottomBar`）**：
  - 改造为浮动胶囊岛（Floating Capsule Pill），叠加 12dp 柔和环境投影与 26dp 圆角。
  - 移出 `Scaffold` 底栏阻塞区，采用全屏穿透浮层布局；页面内容（书籍网格、设置列表、卡片）在滚动时无缝穿流至底栏下方，实时呈现磨砂与透镜折射效果。
  - 为 `Bookshelf`、`Discover`、`Assistant`、`Settings` 顶部四个主页面适配 84dp 底部安全内边距，确保内容滑至末尾不被遮挡。
- **AI 助手浮动液态玻璃输入岛（`AssistantScreen`）**：
  - 重构原先突兀的直角全屏矩形输入条，改为与底部导航栏同构的浮动液态玻璃输入岛（14dp 侧边距、26dp 圆角、三棱镜色散边框与阴影）。
  - 内嵌无边框文本框与发送按钮，软键盘弹出时底栏自适应隐退，输入岛贴紧键盘，消除重叠与视觉割裂。
- **听书贴边悬浮胶囊液态玻璃升级（`ListeningFloatingCapsule`）**：
  - 接入 `liquidGlass` 渲染层与 `HazeState`，胶囊在全屏任意位置拖动时均可实时透视模糊底层文字、封面与插图。
  - 联动朗读状态：播放时开启慢速流动光晕（`enableFlowSheen = speaking && !paused`），暂停时恢复静止水晶通透感。
  - 修复无原生系统 TTS 引擎（如精简模拟器）或书籍标题暂为空时的空指针与不可见问题，内置平滑定时驱动降级与兜底标题。
