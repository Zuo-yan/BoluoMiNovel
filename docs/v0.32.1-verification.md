# v0.32.1 验证记录

日期：2026-10-23（香港时间）。版本字段为 versionCode 37、versionName 0.32.1。

## 已实现

- **液态玻璃渲染核心（`ui/components/Glass.kt`）**：
  - 新增 `Modifier.liquidGlass` 与 `Modifier.staticLiquidGlass`，全向兼容旧接口。
  - **AGSL 原生物理透镜折射（Android 13+ / API 33+）**：编写 `RuntimeShader`，利用圆角超椭圆 SDF 计算法线向量，对底层做物理 UV 弯曲采样，产生真实透镜放大与折射效果。
  - **中性光学透镜质感（全版本兼顾）**：去除动态彩色流光与霓虹彩虹色散，回归内敛纯净中性玻璃；Compose Canvas 绘制层叠加纯白高光倒角与全反射暗边，底色透光度提至 36%，彻底告别乳白塑料感。
  - **环境光晕（`AmbientBackdrop`）**：在全屏底层注入主题色微光晕，为玻璃折射提供灵动光源。
- **底部浮动导航栏液态玻璃升级（`GlassBottomBar`）**：
  - 改造为浮动胶囊岛（Floating Capsule Pill），叠加 12dp 柔和环境投影与 26dp 圆角。
  - 移出 `Scaffold` 底栏阻塞区，采用全屏穿透浮层布局；页面内容在滚动时无缝穿流至底栏下方，实时呈现模糊与透镜折射。
  - 为 `Bookshelf`、`Discover`、`Assistant`、`Settings` 顶部四个主页面适配 84dp 底部安全内边距，确保内容滑至末尾不被遮挡。
- **AI 助手同构浮动液态玻璃输入岛（`AssistantScreen`）**：
  - 重构原先突兀的直角全屏矩形输入条，改为与底部导航栏同构的浮动液态玻璃输入岛（14dp 侧边距、26dp 圆角、中性高光与阴影）。
  - 内嵌无边框文本框与发送按钮，软键盘弹出时底栏自适应隐退，输入岛贴紧键盘，消除重叠与视觉割裂。
- **听书贴边悬浮胶囊液态玻璃升级（`ListeningFloatingCapsule`）**：
  - 接入 `liquidGlass` 渲染层与 `HazeState`，胶囊在全屏任意位置拖动时均可实时透视模糊底层文字、封面与插图。
  - 修复无原生系统 TTS 引擎（如精简模拟器）或书籍标题暂为空时的空指针与不可见问题，内置平滑定时驱动降级与兜底标题。
